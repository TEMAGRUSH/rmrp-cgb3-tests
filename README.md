# Тесты ЦГБ №3 · RMRP

Одностраничный сайт-аттестация для медперсонала ЦГБ №3 на ролевом проекте **RMRP (GTA 5 RP)**.
Только тесты: без разделов о больнице, без регистрации и без сервера.

## Возможности

- **Два варианта по 9 вопросов**: «Помощь и условия» и «Экспертизы и районы».
- Два режима:
  - **Экзамен** — проверка ответов в конце;
  - **Тренировка** — правильный ответ и разбор сразу после выбора.
- Результат: анимированное кольцо, оценка (допуск / зачёт с замечанием / пересдача), разбор каждой ошибки, конфетти при 8–9 из 9.
- История попыток и лучший результат по каждому варианту — в `localStorage`.
- Клавиатура: `1`–`4` — ответ, `Enter` — далее.
- Тёмный дизайн: анимированная сетка, ЭКГ, счётчики, свечение за курсором, появление блоков при скролле, поддержка `prefers-reduced-motion`.

## Структура

```
index.html               страница тестов (единственная)
404.html                 страница ошибки
assets/css/style.css     база: переменные, кнопки, шапка, футер
assets/css/quiz.css      hero, карточки вариантов, вопрос, результат, история
assets/js/tests-data.js  банк вопросов (2 варианта, 18 вопросов)
assets/js/main.js        интерфейс: меню, скролл, появление блоков
assets/js/quiz.js        движок теста, подсчёт, localStorage, конфетти
```

## Локальный запуск

Открыть `index.html` в браузере или поднять статический сервер:

```bash
python -m http.server 8080
```

## Публикация

GitHub Pages из ветки `main`, корень репозитория. `.nojekyll` отключает обработку Jekyll.
